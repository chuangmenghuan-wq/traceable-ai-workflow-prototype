Privacy Policy

Plain-language summary: Future Ability is designed around minimum access. The public deployment scanner uses public GitHub metadata and does not ask for credentials or read repository source files. Private pilot details are stored only when you explicitly submit them.

What the public scanner accesses

When you run a public deployment scan, your browser requests public repository metadata, the default-branch commit SHA, public commit status, and public check-run information from GitHub. The scanner is not designed to fetch repository source files.

Live sandbox data

The reconciliation sandbox creates synthetic demo records in an isolated Supabase project. It is demonstration data, not customer production data.

Pilot and contact submissions

If you submit a pilot request, we store the name, work email, company/team, workflow description, and starting access preference that you provide. If you submit the contact form, we store your email, topic, and message so the request can be handled.

Basic product analytics

The beta records first-party product events such as page view, scan start/completion, sandbox run, and pilot submission. A random session identifier is kept in browser session storage. The event log is intended for product launch measurement and does not intentionally store repository names, source code, production credentials, or advertising identifiers.

Service providers

The public beta uses Vercel for website hosting and Supabase for backend demo, intake, and event storage. The public scanner contacts GitHub's public API when you choose to run a scan.

Retention and requests

Beta operational records are retained as needed to operate and improve the product. You can ask a privacy question or request deletion of a pilot/contact submission through the Contact page. We may need enough information to locate the submitted record.

What we do not ask for in v0.1

The public beta does not request customer production passwords, private GitHub tokens, payment credentials, or broad production mutation authority.
